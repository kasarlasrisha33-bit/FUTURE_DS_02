# Customer Churn Analysis

## Objective
Analyze customer churn data using Python and identify factors affecting customer retention.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- VS Code

## Dataset
Telco Customer Churn Dataset

## Project Steps
- Data Loading
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Observations
- Conclusion

## Visualizations
- Customer Churn Count
- Monthly Charges Distribution
- Tenure Distribution
- Churn by Gender
- Churn by Senior Citizen

## Conclusion
The analysis helps understand customer churn patterns and supports better customer retention strategies.
